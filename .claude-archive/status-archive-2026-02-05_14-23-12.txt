**Key Design Decisions**:
1. **Estimated lag prior**: Uses hardcoded exponential(1/3) prior in Stan model (mean 3 days)
   - Demo script's `--lag-prior-mean` and `--lag-prior-sd` currently not used (future extension)
2. **Cumulative lag generation**: Lags generated as `np.arange(0, window + step, step)` excluding zero lag
   - Zero lag excluded to avoid immediate effect (can be included if window starts at 0)
3. **Output structure**: Each variable gets its own subdirectory with posterior samples, summary, and plots
4. **Report integration**: All three model types generate markdown reports with consistent formatting
